# 抓住串子 · GitHub Pages 版

这是独立的静态网页游戏，部署地址为 <https://guozijan.github.io/zhuazhu-chuanzi/>。项目不使用 B 站 Toy SDK；页面分享、二维码和横屏提示使用浏览器功能。

弹幕库共 200 条。简单、困难、地狱分别随机抽取 48、66、90 条，游戏时长约 55 秒。点击弹幕即抓住，滚出视野自动放行，全部弹幕结束后结算。初次进入有可跳过的教程；直播原声可在画面左上角开关，战绩可生成图片分享。

仓库根目录就是 GitHub Pages 发布目录。保留相对路径，以便项目站点在 `/zhuazhu-chuanzi/` 子路径正常加载。`.nojekyll` 用于原样发布静态资源。

直播图像与音频来自玩家提供的素材，弹幕文字参考玩家提供的录屏并隐去用户名。本作是粉丝制作的模拟游戏，与主播、所属团体、YouTube 及 B 站无关联。游戏中的判定只执行关卡规则，不推断真实发言者的国籍、身份或意图。二维码生成器 `assets/qrcode.js` 的许可见 `assets/qrcode-LICENSE.txt`。
